# AI 分类与搜索优化设计

## 决策流水线
共享 `ClassifyProduct` 流程：型号选择 → 本地规则 → 多证据搜索 → LLM 兜底 → 统一词典归一化 → 现有分类解析/可选创建 → 写入审计。

## 搜索证据
搜索管理器并发请求厂家候选页、厂家域名搜索、经销商页和搜索引擎；收集所有可用结果后去重、打分并返回证据等级。普通搜索摘要属于最低等级，不能单独完成厂家核验。

## 失败语义
分类结果区分 `completed`、`unresolved`、`failed`。不可确认属于 unresolved；数据库/写入/内部异常才属于 failed。瞬时 HTTP 故障按指数退避重试。

## 数据
新增分类审计模型，记录 product、输入型号、选定型号、品牌、类型、状态、规则、证据 JSON、证据等级、原因和时间。迁移沿用现有 AutoMigrate。

## LLM 上下文
只传递按品牌和产品类型筛选的候选叶子分类，限制数量；LLM 只在规则和证据都未确认时调用。
